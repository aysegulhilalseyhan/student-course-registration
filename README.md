# Student Course Registration System

## Description
This project is a console-based Java application that allows students to register for courses, drop courses, and calculate tuition fees. The system demonstrates core Object-Oriented Programming (OOP) principles such as inheritance, polymorphism, interfaces, and encapsulation.

## Features
- View course catalog
- Register for courses
- Prevent duplicate course registration
- Drop registered courses
- Calculate tuition fees
- Console-based interactive menu
- Unit tests with JUnit 5

## OOP Concepts Used
- **Inheritance:** `GraduateStudent` extends `Student`
- **Polymorphism:** Overridden `calculateTuition()` method
- **Interface:** `Registrable`
- **Encapsulation:** Private/protected fields with controlled access
- **Collections:** `Set<Course>` to prevent duplicate registrations
